## What changed

- `CFBundleVersion=1004` adds bounded manual-removal guidance for a reviewed direct npm or Homebrew OpenCodex candidate when automatic package removal remains fail-closed.
- After the app has independently verified that Native Codex restoration is available, the Local OpenCodex screen can present a Helper-style command sheet containing one fixed, path-independent npm uninstall command. The app only copies the reviewed command; it does not execute it, request administrator authorization, or interpolate a candidate path, fingerprint, or user identifier.
- The candidate is re-read before copying. A stale candidate leaves the clipboard unchanged, and nvm, fnm, volta, asdf, or otherwise unverified package-manager identities remain diagnostic-only.
- English and Korean copy, accessibility labels and hints, presentation resolution, clipboard behavior, and narrow-layout coverage are synchronized with the new manual guidance.

## Safety boundaries

- The copied command removes only the reviewed global `@bitkyc08/opencodex` package after Native restoration has been verified. It does not restore Native routing by itself and does not configure or connect a remote Gateway.
- This release does not change manifest revision 5, the v2 Ed25519 trust root, minimum updater `0.3.8-rc.6`, integration protocol 1, Helper protocol 1, receipt or binding schemas, runtime APIs, Relay configuration, routing, credentials, Keychain items, or OCI/Cloudflare deployment state.
- The privileged Helper remains exactly version-bound to the application bundle. Replacing the app can therefore report `update_required`; an administrator-approved Helper update remains a separate action.
- The resident Relay runtime upgrade remains a separate journaled operation. This release does not perform that upgrade, replace `/Applications`, modify `/Library` or Homebrew, or remove an installed Local OpenCodex package automatically.
- The app remains ad-hoc signed with Hardened Runtime, no Team ID, and no notarization. Finder replacement and any required Gatekeeper approval remain explicit user actions.
